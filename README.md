## Monitor de Sistemas em Python

## Explicação

  A aplicação consiste em um programa feito em Python que mostrará as informações
  de software, hardware e rede da máquina que estiver executando a aplicação. 

## Sobre o projeto
  Ele foi feito utilizando diversas bibliotecas, entre elas uma biblioteca de interface gráfica chamada "tkinter". Ademais,
  o programa em si tem a intenção de ser leve, capaz de rodar em qualquer sistema operacional.

## Bibliotecas

    - os

    - GPUtil
    - cpuinfo

    - pathlib

    - collections
    - deque
    - datetime 
    - datetime

    - ttk
    - psutil
    - mmatplotlib.backends.backend_tkagg 
    - matplotlib.figure
    - pynvml

## Requisitos  
> Ter todas as bibliotecas instaladas e ter Python instalado na sua máquina.
