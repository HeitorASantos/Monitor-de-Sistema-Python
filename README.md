# Monitor de Sistemas em Python

  Uma aplicação feito utilizando Python que mostrará as informações
  de software, hardware e rede da máquina que estiver executando a aplicação. 

## 📌 Sobre o projeto
  O Monitor de Sistemas em Python permite ao usuário analisar dados dinâmicos e estáticos da máquina, entre as bibliotecas utilizadas gostaria de destacar a "tkinter", uma biblioteca que permite
  usar uma interface gráfica para ser visualmente amigável para leigos em programação. Ademais,o programa em si tem a intenção de ser leve, capaz de rodar em qualquer sistema operacional.
